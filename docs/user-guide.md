# 使用手册

本手册按新版界面（2026-11-13 临床系统风格）编写。服务启动后，在浏览器打开 API 地址，例如 `http://127.0.0.1:8006/`。安装部署见[部署指南](deployment.md)，账号说明见[独立账号](local-accounts.md)。

> 教学模拟环境：病例为自造模拟数据，尚未经过医学审核。评分和反馈仅用于练习复盘，以带教医师意见为准。

## 一节课的典型流程

1. 教师登录，在“班级与任务”新建班级，在“学生名单”中粘贴“账号,姓名”导入学生，导出初始密码发给学生。
2. 教师在“训练任务”选择病例和截止日期，点击“布置”。
3. 学生用初始密码登录，系统要求先设置新密码，之后进入“我的任务”，点击“开始”。
4. 学生完成问诊、检查、病历、鉴别诊断、诊断和处置，然后点击“提交并评分”。
5. 教师在班级的完成情况表中查看每名学生的得分，点“评分复核”处理有争议的项目；点“本班学情”查看五个环节的得分率和高频失分项。

## 学生

**登录与改密。** 账号由任课教师发放。首次登录或密码被重置后，必须先设置新密码（12～128 位）。以后可在右上角“账号设置”中修改密码。忘记密码请联系任课教师重置。

**我的任务。** 列出教师布置的病例和截止日期，以及每项的状态和最好成绩。按钮依次为“开始”“继续”“再练一次”“查看复盘”。也可以在“病例库”中自选病例练习，在“训练记录”中查看全部训练。

**问诊与检查。** 页面顶部的患者条显示性别、年龄、主诉、科室和模拟时间。像面对真实病人一样用口语提问即可，患者只回答被问到的内容。对话上方的“问诊结构”按 8 个方面标记你已问到的部分，它只根据你自己的提问生成，不会透露病例内容，也不影响评分。右侧“检查申请”是全院检查目录（46 项），所有病例都相同，不会提示该开什么。可以按名称检索或按类别筛选，每项都标明费用和回报时间，点“开单”即可。结果要在模拟时间推进后才回报，可以用“推进时间”往前推。与病情无关的检查只会回报“未见明显异常”，而且会在评分中扣分；血常规、电解质等常规基础检查不扣分。顶部监护带显示累计检查费用。拖延可能导致病情变化，页面会红色提示。

**病历与诊断。** 左侧写病历，可“插入模板”，写完点“保存”。右侧勾选需要鉴别的疾病，分别填写支持点和不支持点，并勾选这些判断依据来自哪几条问诊或检查记录，然后点“提交”。最后填写主要诊断并提交。有未保存的修改时，标签页会出现黄点，离开页面前也会提醒。

**处置与提交。** 选择处置。只点“仅记录计划”不算执行；勾选确认后点“执行”才算实际执行，执行后不可撤销。右侧清单全部完成后，点“提交并评分”。提交后训练变为只读。

**评分与复盘。** 查看总分和五个环节的得分条。“扣分点与改进建议”只列失分项；“问诊结构”列出漏问的方面；“分环节反馈”点击“生成反馈”后显示；“操作回放”按时间顺序列出全部操作。对评分有疑问时，把训练编号告诉老师。

## 教师

| 菜单 | 用途 |
|---|---|
| 班级与任务 | 新建班级；粘贴名单批量导入学生（新账号自动生成 16 位一次性初始密码，可导出 CSV；已有账号直接加入）；重置密码、停用/启用、移出本班；布置任务（病例、截止日期、要求）、撤回任务；在完成情况表中查看每人的最好得分率和待复核标记，并可导出 CSV |
| 学情统计 | 按班级筛选，查看训练次数、提交数、待复核数、平均得分率，以及各病例五个环节的得分率和高频失分项。训练明细可按病例或“只看待复核”筛选，从这里直接进入评分复核或反馈复核 |
| 病例管理 | 浏览各版本病例；编辑症状、触发词、检查与回报，保存为新版本草稿（已开始的训练不受影响）；结构校验后送审，只有在真实医学审核完成后才能填写审核人并发布 |
| 评分复核 | 逐项裁定分数并填写对学生可见的说明。得分项必须引用封存前的真实事件，裁定另存为独立版本，原规则分保留 |
| 反馈复核 | 核对模型生成的反馈原文和证据，逐环节修订后发布，学生刷新后可见 |

学情统计中的分数是原规则分，未合并教师裁定。病例尚未经过医学审核，统计结果只能作为教学参考。

**病例编写技巧。** 运行 `python scripts/eval_dialogue_coverage.py --detail`，可以看到 40 个常见问法在每个病例上的回答情况。标为“unconfigured”的，是学生会问但病例里没写的内容。修改后运行 `scripts/run_dialogue_eval.py`，检查是否引入了多答或泄露。

## 管理员

教师账号需要由管理员在命令行创建，学生账号可由教师在界面中导入。

| 操作 | 命令 |
|---|---|
| 新建教师账号 | `python scripts/manage_accounts.py create <账号> --role teacher --name <姓名>` |
| 重置密码 | `python scripts/manage_accounts.py reset-password <账号>` |
| 停用账号 | `python scripts/manage_accounts.py disable <账号>` |
| 重启本机预览 | `powershell -ExecutionPolicy Bypass -File E:\AI数字病人临床思维训练\scripts\restart_account_preview.ps1` |

密码通过交互方式输入，不要写在命令行或文件里。班级、任务和改密功能仅在独立账号模式（`APP_AUTH_MODE=local`）下可用，演示模式下返回 409。
