## 一、课题定位

课题1“[教学] AI 数字病人临床思维训练”，难度高，高级任务激励金 ¥7,000。

官方建议功能：

- 前端：模拟医学教学平台，包括虚拟病人档案、问诊对话界面（文字/语音）、检查检验开单与结果回传、病历书写、临床思维评分与轨迹回放、教师端病例管理。
- 后端：以 NEXENT 作为数字病人引擎。按设定病情回答问诊，只回应被问到的症状和体征；根据学生的诊疗决策动态演进病情和检查结果；按临床思维链五个环节（病史采集、检查选择、鉴别诊断、诊断、治疗）自动评分并给出反馈。

## 六、提交到 AgentsHub 的规范（README）

1. Fork 官方仓库。
2. 放到 `行业智能体/医疗/<智能体目录>/` 下，目录包含：
   - `agent.json`：**由 Nexent 平台“智能体开发”导出生成，不手写**，内含基本信息、系统提示词、模型参数、绑定的 Skill 与 MCP、知识库引用和示例对话。
   - `README.md`：使用说明和配置指引。
   - `skills/`、`mcps/`：有自定义依赖时提供。
3. 提交 PR，标题格式为 `[new agent] <display_name>`。维护者审核通过并合入后，才算交付。
4. 审核标准：agent.json 格式正确、内容完整；提示词清晰，无敏感内容；已通过 Nexent 平台的基本功能测试；不侵犯第三方知识产权；不含恶意代码。
5. 内容按 MIT 许可证发布。

**待向维护者确认的一点：** README 规定的目录只放 agent.json、README、skills、mcps，而需求包还要求提交完整的前后端源码、部署文档和视频等。两者的关系需要先确认：源码是否也放进 AgentsHub 目录，还是放在独立仓库、由 README 链接过去。

## 七、优先级建议

1. 跑通 Nexent 真实链路，在平台上导出 agent.json（审核硬条件）。
2. 降低真实模型的响应时延（首字 ≤5 秒），否则通用验收不过。
3. 组织至少 3 名学生训练，请教师人工评分，计算一致率（≥85%）。
4. 按“20 轮问答”格式做一致率自测（≥95%），并继续提升对未见问法的稳定性。
5. 补齐错误决策的演进分支（不当检查、不当处置），保证 100% 触发。
6. 在干净环境按部署文档部署一次，录制 3～8 分钟演示视频。
7. 向维护者确认源码的提交位置，按格式提交 PR。
