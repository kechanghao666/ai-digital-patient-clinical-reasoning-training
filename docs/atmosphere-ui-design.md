## 本轮设计

首页使用一段明确的教学语境：“临床思维，从倾听开始”。左侧是两行中文衬线标题和短说明，右侧为原创光环；下方直接进入可搜索病例列表。光环仅作装饰，在辅助技术中隐藏，不代表患者、生命体征、进度或模型在线状态。

底色由平面石墨灰调整为墨蓝。背景用两个低对比光场缓慢移动，光环以18秒往返周期轻微转动、升降与缩放。背景采用22秒往返周期；没有闪烁、快速旋转、鼠标追踪或持续粒子计算。只对transform和opacity做连续动画，图形本身为本地静态SVG。

左栏“动态背景”可随时暂停；同一次浏览会话切换身份时保留偏好，刷新/新会话默认开启。系统启用减少动态效果时自动停用所有动画。暂停仅影响装饰，不提交训练或教师审核动作。

排版用本地嵌入的中文字体：开源Noto Sans SC经裁剪重命名为Clinic Sans，Noto Serif SC经裁剪重命名为Clinic Serif。保留原版权和SIL OFL许可证，来源、体积与哈希记录于[字体清单](../frontend/assets/fonts.json)。标题使用38字的衬线子集，界面字体包含当前UI/病例词汇；其他字符回退到系统字体。不同系统的回退字形可能有差异，后续扩大病例库时应重新生成字库或评估完整字体交付。

标题约36–50px，表单/正文约15px，病例标题16px，正文行距约1.8，常用按钮至少42px高。小屏保留标题，装饰缩至右侧并降低透明度；桌面训练仍为任务分栏，手机纵排。主内容避免大段使用衬线字，输入区保留原生标签、焦点、禁用和错误状态。

新资源约650KB（字体、图形、图标及许可证），不增加生产依赖。浏览器验证没有外部字体、图形或图标请求；真实模型请求仍由既有后端处理，这不意味着系统可以脱网训练。

## 可复用工作提示词

```text
为数字病人临床思维训练设计一个兼顾阅读舒适与视觉品质的深色工作区。
保留当前病例、训练、复盘和教师复核功能，不改变数据与权限边界。

借鉴Claude对标题字体与留白的处理，ElevenLabs的柔和材质与单一视觉焦点，
以及Cursor对产品内容和操作区的分工。不要复制品牌、专有字体或素材。

首页左侧放两行舒展的中文标题与简短说明，右侧用原创、低饱和的光影图形。
下方直接进入病例列表，不重复使用圆角卡片，也不虚构图表和进度数据。
主操作页保持内容优先。正文使用清晰的中文无衬线字体，增加字号与行距，
避免所有标题都粗重，避免用灰度过低的小字来制造所谓高级感。

动态背景缓慢、可暂停，遵循系统减少动态效果设置；装饰不接收鼠标事件，
不影响表单、键盘焦点和文字对比。手机减少装饰面积，保留清楚的主要动作。
字体与素材本地交付，说明许可与缺字回退策略。

以实际截图、真实控件操作、动画暂停和窄屏重排验证结果，
不要把工程检查通过当作用户已经认可视觉设计。
```

## 验证范围

相关六组工程检查94项通过，包含背景偏好跨身份保留且不创建训练的新增检查。浏览器确认字体及图形加载、动画实际变化、暂停、系统减少动效、390/320px病例检索、已有训练恢复、封存只读和教师复核页面。没有进行新的真实模型问诊，也没有写入教师批准；正式业务库哈希不变。

当前本地8506预览已展示新版。截图与结果见[本轮证据](evidence/2026-11-13-atmosphere-ui.json)。仍未发布远端，未完成低性能设备、完整读屏和真人舒适度评估；既有约6秒模型响应问题没有在本轮处理。
