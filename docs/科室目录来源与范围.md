# 科室参考目录来源、范围与计数

核对日期：2026-11-25。目录代码当前从 `962d31836e672fc98c8ee88e431a52428fde5942` 的未提交工作树扩展；仅为单校部署可启停的参考目录，不是本校真实建制清单。没有校方书面科室清单，任何新增参考项均默认不启用。

## 1. “完整”的参照范围

本次只以《医疗机构诊疗科目名录》及其明确修订为来源，不把住院医师规范化培训专业、本科专业、学校教研室或医院习惯科室名称拼接到同一目录。该目录按医疗机构执业登记的一级/二级诊疗科目编制；原目录使用说明指出，机构实际科室名称可不同于目录名称。

国家卫生健康委公布页的可检索正文载有 1994 年原通知、附件目录和使用说明，并列出有关修订文件；重庆市卫生健康委 2020-06-01 官方转载给出合并表并标注“最新版本号：20120318”。重庆市卫生健康委 2024 年答复另称该目录有 34 个一级、143 个二级诊疗科目。此处将 **34/143** 记为公开的总数交叉核对口径，不把转载页版本标记当成独立文号或国家卫健委重新发布的版本。

本项目实际可选的子集是 **34 个一级项、120 个有明确目录编码的命名二级项**。它不是完整的 34/143 目录。所选范围中未发现需要修改现存病例编码；本轮不重写病例、不迁移旧值。

## 4. 未纳入、未决与来源计数核对

### 4.1 明确排除

- 原合并文本中有 **138 个按代码形态识别的 L2 行**；其中 17 个“其他/其它”兜底项不作为明确专科：`03.11`、`04.09`、`05.06`、`06.06`、`07.12`、`08.06`、`09.06`、`11.04`、`12.13`、`13.03`、`15.08`、`16.07`、`23.06`、`30.06`、`32.11`、`50.18`、`51.06`。这些条目保留在排除清单中，不能误认为源文件不存在。
- `99.01 感染（管理）科` 的父项 `99 管理科室` 属行政管理分类，不进入临床教学目录。合计排除 **18 个已编码 L2 行**，故本系统的已编码、非兜底命名 L2 为 `138 - 18 = 120`。
- `61 重症监护室（综合）` 是监护单元代码，不与 `28 重症医学科` 混为同一层级；`79 其它` 是兜底项；`99 管理科室` 是行政项。这 3 个非目录临床 L1 项不计入 34 个一级科目。
- 六项器官移植代码 `04.01.01`、`04.01.02`、`04.01.03`、`04.04.01`、`04.05.01`、`04.06.01` 是三级项目，不计入 L2，也不加入教师可选科室目录。

2. 卫生部令第19号《医疗美容服务管理办法》第2条列明美容外科、美容牙科、美容皮肤科、美容中医科四个二级科目；目前核验到的该条未给出目录代码。目录片段及官方 34/143 总数不足以证明具体 `14.xx` 码，故作为 4 个未编码类别待核，不猜编码、不进入可选目录。
3. **数量交叉核对**：20120318 合并文本中统计到 138 个已编码 L2 行（其中包含上述 17 个兜底项及 `99.01`）；加上原始目录有而合并文本缺失的 `07.07` 与法规确认但编码未核实的四个医疗美容二级名称，算术上为 143，与 2024 年重庆市卫健委答复的 143 一致。该算术对应关系只是对公开总数的待核解释，不证明主管部门统计口径相同，也不解决 5 个类别的代码/版本状态。因此系统仍只收录 120 项，并标为参考子集，不能称国家完整目录。
