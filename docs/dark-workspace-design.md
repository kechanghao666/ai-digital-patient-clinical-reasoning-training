## 设计决定

页面的主体是一张可以持续工作的画布。病例库使用连续登记列表，每行对应一个真实病例，按编号/版本、标题/主诉、专科/审核状态、开始动作排列。最近训练是来自真实记录的一条恢复入口。没有虚构完成率、排行榜或装饰仪表盘。

训练页采用“上下文—步骤—任务”的顺序。顶部展示病例与真实模拟状态；四个原生页签保持输入；问诊和检查分栏，病历和判断分栏，处置与封存分栏。去除面板外框，只让需要区分职责的纵向边界存在。窄屏改为纵向排列，病例列表仍保留标题、状态和开始按钮。

教师页沿用同一视觉规则，反馈和评分查找表单在桌面将账号、训练编号并排，窄屏纵排。评分表、原始证据和复核表单继续保留；不为减少界面信息而隐藏审核限制。

```text
┌──────────────┬──────────────────────────────────────────────────┐
│ 工作空间     │ 教学模拟提示                                     │
│ 学生 / 教师  │ 当前位置 / 病例库                                │
│              │ 标题、用途                              真实数量 │
│ 病例库       │ 最近训练 / 恢复                                  │
│ 我的训练     │ 搜索                                   专科筛选  │
│              ├────────┬───────────────────────┬────────┬─────────┤
│ 当前账号     │ 编号   │ 病例标题与主诉        │ 状态   │ 开始    │
│ 连接设置     │ 编号   │ 病例标题与主诉        │ 状态   │ 开始    │
└──────────────┴────────┴───────────────────────┴────────┴─────────┘
```

## 可复用的设计提示词

以下为本项目的原创工作提示词，是将来源方法应用到具体系统后的设计简报，并非复制任何平台模板。

```text
为“AI数字病人临床思维训练”重构可运行的界面。
使用者是进行病例练习的学生，以及编写病例、复核训练的教师。
学生的关键路径是：选择真实病例 → 问诊与检查 → 保存病历和提交判断
→ 确认模拟处置 → 封存 → 阅读反馈与原始证据。

视觉方向：深色专业工作区，石墨灰、中等信息密度、少量冷蓝强调。
参考 Linear 的导航层级、VS Code 的主任务与支持面板分工，
结合 Carbon/Spectrum 的深色明度分层；不要复制其品牌或照搬代码编辑器。

病例库使用连续、对齐的列表，不能用等大的圆角卡片网格。
每行清楚呈现编号、标题、主诉、专科、审核状态和真实开始操作。
训练页使用上下文栏、稳定页签和任务分栏；保持会话草稿与原有动作。
标题、正文、辅助文字有明确层级；通过间距表达关系；边框只用于必要边界。
不要加入装饰性图表、假完成率、无用大标语、霓虹光晕或不可操作按钮。

所有动态数据来自真实接口。公开病例字段之外的信息不能出现在学生端。
保留未保存提示、处置确认、封存只读、身份隔离及教师反馈复核限制。
状态必须有文字，不仅依赖颜色。键盘操作必须保留焦点，320px仍可使用。

先画出页面信息结构，再实现。分别检查桌面、390px与320px截图，
检查长中文标题、空搜索、禁用按钮、下拉菜单、焦点和错误状态。
视觉修改之后必须重新走通实际训练流程，并明确尚未验证的范围。
```

复查提示词：

```text
看实际运行截图，逐项核对：
1. 页面首先告诉用户当前任务吗，还是先堆出功能区？
2. 哪些外框可以用间距替代？哪些文本/按钮在争夺不必要的注意力？
3. 病例、状态、动作能否快速横向比较？主诉是否被标题挤掉？
4. 深色背景上的文字、焦点和弹出菜单是否都清楚？
5. 手机有没有溢出、被遮挡的动作或难以辨认的小字？
6. 改动有没有让草稿、身份、封存状态或医学审核边界变得不清楚？
只修复截图和操作中有证据的问题，然后复验受影响的流程。
```

## 实现与边界

沿用现有 Streamlit、接口和数据结构，没有新增生产依赖。动态病例文本经过 HTML 转义；原生输入、角色选择和页签保留操作语义。导航样式引用当前 Streamlit 的结构和测试标识，未来升级时应重新检查。

视觉质量由实际截图和用户评价共同判断；工程检查不能代替审美认可。临床审核、正式身份系统和实际人员验收属于既有工程/业务门槛，本次外观改版没有将其标记完成。未重新发布旧版卡片设计，也未发布本轮深色版本到远端。
