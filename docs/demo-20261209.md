## 二、浏览器演示（选 CASE-001 心内：学生训练 → 教师复核）

- 可复跑入口：`node web/e2e/smoke.mjs`（合成账号 + 本地模拟器，学生训练封存后教师只读复核，13/13）。真实模型入口见 [`o10a-latency.mjs --three-turns`](evidence/2026-11-27-o10a-latency-timeline.md)（需另行授权）。
- 演示路径：学生登录 → 病例库选 CASE-001 → 问诊（主诉、时间、部位、性质、放射、出汗、既往史、家族史；问「我是不是心梗」只答已授权事实）→ 开心电图/肌钙蛋白 → 推进时间看回报 → 写病历、结构化鉴别（主动脉夹层/肺栓塞，勾选来源事件）→ 提交诊断 → 执行再灌注 → 封存 → 看五环节评分与扣分/改进/回放 → 切换教师 → 班级看板 → 打开一条评分复核（裁定不覆盖原分）。
- 录屏：[6 分钟脚本](demo-video-script.md)（0:00 登录→病例库；0:30 问诊；1:50 开单回报；2:40 病历鉴别诊断；3:30 处置封存；4:10 反馈回放；5:00 教师复核；5:40 结尾）。画面左上角常驻「教学模拟环境，非真实患者，不用于真实诊疗」，并标注「本地规则模拟器」。视频不提交 git，按官方要求另行上传。
