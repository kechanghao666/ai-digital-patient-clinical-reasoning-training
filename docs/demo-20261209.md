## 一条命令运行隔离浏览器演示

先按部署说明安装 Python 锁定依赖，在 `web/` 执行 `npm ci` / `npm run build`，安装 Edge 或 Chrome；随后在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe web/e2e/demo.py local-only/new-browser-demo
```

启动器自动创建临时数据库、随机端口和合成教师账号，固定 local 认证与 simulator，不访问已有服务或业务库，结束后停服并清理临时数据。默认输出目录和显式目录均不得覆盖旧证据。浏览器执行教师建班/导入/布置 → 学生改密/问诊/开单/回报/病历/鉴别/诊断/处置/封存/反馈 → 教师看板/评分复核/病例管理。失败返回非零退出码；合成临时密码不作为交付材料。

`smoke.mjs` 是内部浏览器步骤脚本，依赖启动器提供环境，不再把它单独作为隔离启动命令。录制参数、实测视频与证据见[视频说明](demo-video-script.md)。其余四例逐事件轨迹可离线核查；现场抽取仍需在最终环境实际操作，不能用本页预先判定通过。
