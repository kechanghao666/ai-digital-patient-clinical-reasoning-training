## 一、状态定义

| 状态 | 含义 | 使用规则 |
| --- | --- | --- |
| **未实现** | 没有对应模块、入口或数据字段 | 不得用文档、规划或空目录充数 |
| **已实现但未达标** | 有实现与可复核证据，但官方指标或可用性未满足 | 不得标为完成；须写明差多少、怎么验 |
| **证据不足** | 实现存在，但现有证据不足以判定达标 | 保留为待证，不推定通过 |
| **已实现（工程口径）** | 工程链路与测试通过，达到官方文字要求 | 不等于医学审核、人员评测或官方验收通过 |

专家评价、真实学生试用、官方手续不属于工程状态，单独列在第四节，不由工程自签。

## 六、本轮结论

1. 官方工程要求的当前分类、证据与后续验收见[官方要求核对](官方要求核对.md)。无一项可写成“官方验收通过”；工程单测通过不抵消临床、真人、性能或部署门槛。
2. 病例生命周期来源和操作审计已有工程实现及 22 项专项回归，但医学审核人身份、依据映射、停止恢复/归档、版本回滚和审计完整运维仍开放。
