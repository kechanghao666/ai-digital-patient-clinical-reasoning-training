# 演示视频脚本（目标 6 分钟，官方要求 3–8 分钟）

对应官方交付物“3～8 分钟闭环演示视频”。本文只是拍摄脚本，**视频尚未录制**。

录制前需要准备：

- 重启预览，确保使用最新代码。
- 准备一个学生账号和一个教师账号。
- 学生账号先完成两三次已封存的训练，这样看板上有数据。
- 只展示自造病例，不出现任何真实人员信息。
- 片头和片尾都要显示“教学模拟环境，非真实患者，不用于真实诊疗”。

如果录制时使用真实 Nexent 模型，画面中要显示服务模式；如果用本地模拟，要在旁白中说明。

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00–0:30 | 登录页 → 病例库 | 课题1 AI数字病人；五个专科的模拟病例；学生和教师两种角色 |
| 0:30–1:50 | 胸痛病例问诊：先“您好，哪里不舒服”，再追问时间、部位、性质、放射、出汗、既往史和家族史；问“我是不是心梗”时患者不回答 | 患者只回答被问到的已授权事实，不泄露诊断；“问诊结构”标签随提问逐个点亮 |
| 1:50–2:40 | 开心电图和肌钙蛋白 → 推进时间 → 查看回报 | 检查要开单、要等待，结果由检查系统给出，不由患者说出 |
| 2:40–3:30 | 写病历，填鉴别诊断（主动脉夹层、肺栓塞）的支持和反对证据并勾选来源事件，提交诊断 | 鉴别结构化：候选、证据和事件引用 |
| 3:30–4:10 | 选择再灌注路径并确认执行 → 封存 | 计划和执行分开；封存后只读 |
| 4:10–5:00 | 反馈与回放：五环节得分、扣分原因、改进建议、问诊结构复盘、操作回放 | 评分可追溯到事件 |
| 5:00–5:40 | 切换教师 → 班级训练看板：各病例五环节得分率、高频失分项 → 打开一条评分复核 | 教师按“概览 → 病例 → 单次训练”逐层查看；裁定不覆盖原分 |
| 5:40–6:00 | 结尾字幕：评测集结果、未完成事项（医学审核、真实学生评测） | 如实说明当前阶段 |

**录制后检查：**

- 视频时长在 3–8 分钟之间。
- 画面中没有密钥、密码或账号信息文件。
- 页面上的提示文字与本脚本旁白一致。
- 视频文件不提交到 git，按官方要求的方式另行上传。
