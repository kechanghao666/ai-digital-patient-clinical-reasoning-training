# 病例版本停止新训练

基线 `9fa11e1`。本轮只做一件事：教师可停止一个**已发布病例版本**接受新训练；已有训练与封存评分仍按原版本回看。未改科室字段、教学依据继承、病人问诊、评分与反馈逻辑；真实模型调用 0 次，未部署。

## 语义

1. **按版本停止**：作用对象是 `(case_id, version)`，不是整个公开号，也不是整个病例。
2. **不回退**：学生入口先选出最新已发布版本，再检查是否停止。若最新版已停止，直接拒绝，不会悄悄回退到更老的已发布版本。
3. **不误伤新版**：若同一公开号还有更新且可用的已发布版本，停止旧版本不影响新版；学生仍使用最新版。
4. **不动历史**：停止只拦截“新建训练”。停止前已建立的训练可继续读取、完成与封存；已封存评分、事件、审核结论、病例文件均不改。
5. **可重复**：同一版本重复停止返回原记录（`already_stopped=true`），不新增记账；同一请求编号不能改用于另一版本。
6. **重启仍生效**：停止记录写入既有集成库 SQLite，进程重启后仍拦截。

## 入口口径

| 入口 | 停止后的行为 |
| --- | --- |
| 学生病例库 `GET /api/cases` | HTTP 200；该公开号不再出现（不回退到旧版） |
| 公开号直达 `POST /api/sessions?case_id=...` | HTTP 409：“该病例版本已停止接受新训练，请联系教师重新选版” |
| 教学任务 `POST /api/assignments/{id}/start` | 有未完成训练：按原会话继续；无未完成训练：409 同一提示 |
| 教师新建任务 | 指向已停止公开号时 422 “病例不存在或当前不可用于训练” |
| 学生任务卡片 | 无进行中训练时禁止开始或重练；有进行中训练时允许继续。若已有封存成绩且又开始了一次重练，继续进入本轮，复盘进入最近一次封存训练 |

## 接口与存储

`POST /api/teacher/cases/{case_id}/versions/{version}/stop`

```json
{ "reason": "停止原因（1–500 字）", "request_id": "客户端幂等编号" }
```

返回：`case_id`、`case_version`、`public_id`、`stopped_at`、`stopped_by`、`reason`、`already_stopped`。

- 权限：`current_teacher`；学生调用 403。
- 只允许 `published` 版本；草稿、校验通过、待审核返回 409。
- 记录表 `case_training_stops` 位于既有 `INTEGRATION_DB_PATH`，主键 `(case_id, case_version)`，唯一 `(teacher_id, request_id)`。
- 不写病例文件、不改 `review_status/reviewer/review_date`、不碰封存快照。
- 教师列表 `GET /api/teacher/cases` 增加 `training_stopped/stopped_at/stopped_by/stop_reason`。

## 页面

病例管理页选中已发布版本后显示“停止新训练”：

- 面板标题与确认文案都写明 `公开号 v版本`。
- 必须填写原因并勾选确认；按钮在原因或确认缺失时禁用。
- 成功后列表面板显示“已停止新训练”，审核与发布区显示操作者、时间、原因，并注明历史训练与评分保留。
- 停止后不提供恢复按钮（见后续）。

## 非目标与后续

- **不提供恢复/撤销**：停止是单向操作；如误停，本轮只能通过新的已发布版本继续教学。恢复/撤销应作为独立任务，先定义审计与权限。
- **不做归档/删除**：病例文件保留；公开号不因停止被删除。
- **不改任务版本策略**：现有教学任务只存公开号、跟随最新已发布版本；最新版停止时任务被明确阻断，教师需重新选版或新建任务。若需要“任务固定版本”，另立任务。
- **不做科室/亚专科字段**：按院校启用的完整目录是下一项独立任务。
