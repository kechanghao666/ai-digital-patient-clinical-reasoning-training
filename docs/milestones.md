# 里程碑与责任分工

依据：[官方规则](https://gitcode.com/org/ModelEngine/discussions/26)。D为实际确认“报名成功”的日期；截至2026-11-07公开确认未查到，D待核实，不能以发表评论日期代替。

| 节点 | 时间 | 完成条件及责任 |
|---|---|---|
| 资格与实名 | 正式流程前 | 负责人确认实名、报名成功及D |
| 启动材料 | D后3个自然日内 | 官方Fork、课题骨架、过程仓库登记、小助手权限、方案/评测/里程碑/字段草案；负责人落实官方手续，开发agent提交材料 |
| 首例平台 | 优先开发 | 开发agent实现真实Nexent、工具、知识库和首例闭环；负责人提供目标环境 |
| 中期演示 | D后30个自然日内 | 可运行核心链路及演示证据 |
| 定期更新 | 间隔不超过7个自然日 | 远端提交、Issue、测试或阶段说明 |
| 五专科与评测 | 候选版本前 | 教师新增、五例闭环、真实评测、性能和复现；负责人安排学生与专业人员 |
| 候选版及PR | 2026-12-24，个人计划 | 全部交付物、自测、平台导出及PR材料 |
| 完整交付 | 2026-12-31，报名承诺 | 官方PR合入main及完整材料；预留维护者审查和整改时间 |
| 验收 | 正式交付后30天内，官方安排 | 现场复现、指标复算与评审 |
| 首次不通过整改 | 收到结果后7个自然日内 | 修正版本、说明和重提 |

延期须至少提前5个自然日申请，经活动组确认生效，一般不超过15个自然日。个人计划不代替活动最终截止日或保证按时合并。
