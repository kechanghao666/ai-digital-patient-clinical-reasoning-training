## 2. 状态定义

| 状态 | 使用口径 |
| --- | --- |
| 已实现（工程口径） | 代码存在且相应工程回归实际通过；不等于医学质量、真人试用或官方验收通过 |
| 已实现但未达标 | 有实现，但已知未满足目标指标或必需流程 |
