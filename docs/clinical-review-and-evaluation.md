# 五专科医学审核与验收记录

本表供专业人员审核模拟病例和量表，审核人与结论由实际审阅者填写。病例链接、当前缺口与已有候选规则见[五专科决策审查](clinical-decision-review.md)。正式抽检指标见[官方需求包](https://atomgit.com/ModelEngine/AgentsHub/blob/main/需求包详情与交付要求.md#topic-01)。

| 病例 | 优先审核项 | 供审阅者定位的一手来源 | 审核人、日期、结论 |
| --- | --- | --- | --- |
| CASE-001 心内 | 核对心电图回报与处置顺序、延误起点、评分引用的可见证据 | [2025 ACS 指南，STEMI 再灌注章节](https://www.jacc.org/doi/10.1016/j.jacc.2024.11.009) | 待填 |
| CASE-002 普外 | 核对影像与外科会诊的适用条件、复杂与非复杂病例差异、延误是否有明确因果 | [WSES 2025 版指南，诊断与处置章节](https://doi.org/10.1001/jamasurg.2025.6218) | 待填 |
| CASE-003 神经 | 核对起病、最后正常和到诊时钟，区分明确和不明时间，并审核影像及评分所需证据 | [2026 AHA/ASA 指南，急诊评估和影像章节](https://www.ahajournals.org/doi/10.1161/STR.0000000000000513) | 待填 |
| CASE-004 呼吸 | 核对病例人群、诊断证据与严重度判定，检查配置是否能覆盖例外 | [ATS 成人 CAP 指南，诊断与管理问题](https://doi.org/10.1164/rccm.202507-1692ST) | 待填 |
| CASE-005 内分泌 | 核对血钾证据、补液与胰岛素动作拆分、监测与例外，明确哪些缺项触发复核 | [2024 成人高血糖危象共识，Potassium 与治疗监测](https://pmc.ncbi.nlm.nih.gov/articles/PMC11272983/) | 待填 |

每例审阅时记录病例版本、量表版本、引用条目及适用范围。分别填写正常路径、漏检查、检查后延误、不当检查、不当处置、纠正或例外路径。每行保留「学生当时已知证据 → 决策 → 是否触发演进及因果 → 学生可见变化 → 分项计分和反馈 → 审核结论」。不适用项记录理由。审核完成后另存新病例版本和对应依据。

| 正式验证 | 逐条记录字段 | 官方目标 |
| --- | --- | --- |
| 问答抽检 | 问答序号、病例及版本、学生提问、完整回答、当时允许披露的事实、评审判断及理由 | 20 轮一致率 ≥95% |
| 学生与专家对照 | 学生匿名编号、版本、完整轨迹、五环节系统原分、专家独立分、证据、差异及待复核原因 | 至少 3 名学生，一致率 ≥85% |
| 明显错误决策 | 事先审核的场景编号、输入、预期演进和反馈、实际输出、判定 | 触发率 100%，反馈准确指出错误环节 |
| 现场及部署 | 版本、环境、随机用例、实际轨迹和运行结果 | 五例均可用，专项随机 1 例，同时准备通用随机 3 条以上用例 |

开始采样前冻结代码、病例、量表、依据和平台模型配置。教师先独立完成评分，再与系统原分比对。按评审确认的分母、容差及聚合方法报告一致率，保留逐项记录。填写完成的人员与样本记录保存在受限目录。复现时使用匿名编号和脱敏轨迹。
