# 光标交互与账号入口

> 2026-11-13 后续调整：按用户要求移除登录页和工作区的动态背景开关，动效始终默认开启，仍遵循系统减少动态效果设置。16 项相关测试通过；运行中的 8508 页面已验证无开关、光环持续运动且响应光标。下方提及页面暂停开关的内容为此前版本记录。

2026-11-13。用户认为前一版动效接近静态，并明确选择本项目独立账号、学生与教师分权。本轮在既有中文排版与深色工作区上增加可感知的动态反馈和真实账号边界，不重做病例或评分规则。

## 视觉决定

底色保持墨蓝 `#10141c`，正文 `#ebedf2`，次要文字 `#a9b1c0`，强调 `#b5c6e8`，光环以低饱和冰蓝与少量暖色交织。Clinic Serif 用于“临床思维，从倾听开始”，Clinic Sans 用于账号、密码、病例及教学操作，字库和许可沿用本地资源。

登录页采用左右展开的构图：左侧流动光环与短标题，右侧居中的登录表单；表单去掉外围卡片。顶栏放品牌、动效开关与连接设置。移动端压缩装饰区域并纵排，原生输入标签、键盘焦点和密码隐藏保留。

病例库沿用内容列表，光环集中在页首。鼠标位置影响光环倾斜与位移，柔和光晕跟随位置；这类随操作发生的变化提供直接反馈。无指针操作时，网格和三个光点继续流动，避免再次呈现接近静态的效果。装饰不代表病例状态、模型在线情况或医学数据。

## 实现与使用边界

使用已安装 Streamlit 1.67.0 的 `st.html(..., unsafe_allow_javascript=True)` 运行仓库内固定脚本；没有 iframe 父页面穿透、远程脚本、额外渲染依赖或用户内容拼接执行。Canvas 绘制光环，原 SVG 作为无法创建画布时的静态回退。

绘制限制约 30 帧/秒，像素比例最高 1.75；每页只有一个控制器、一个画布和一个光晕，页面重绘不累积监听器。关闭动效时画布冻结；系统减少动态效果设置禁用自动动画与光标追踪；后台标签停止请求绘制。触屏不追随触点，也不拦截滚动或输入。

登录机制、账号开通与边界见[独立账号](local-accounts.md)。界面本身不决定权限，学生不能靠修改显示内容或请求头获取教师功能。

## 验证

实际浏览器验证了空闲动画、左右光标移动、暂停时画布与位置不变、减少动态效果、重复重绘的单实例，以及桌面/390/320px登录布局。原业务库 SHA-256 保持不变。此结果不代表已获得用户审美认可或在所有显卡、触屏与辅助技术中验收。

前一版只有轻微 CSS 动画的记录保留于[光影工作区](atmosphere-ui-design.md)，其“无鼠标追踪”等描述属于历史实现。
