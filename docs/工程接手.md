## 接下来做什么

本轮交给下位工程 agent 的是 CAP-001 v1/v2 的 `f_dyspnea`，固定集的 6 个剩余评分偏差均在此项。[六次独立问诊](../evaluation/reports/cap_rest_baseline_9bde2f8.json)另行记录措辞对照。两个版本均出现以下行为：

- “活动后有没有气短，休息后会不会好一点？”得到“活动后气短，休息时好一点。”，得 1/1。将“好一点”改为“好转”，只答“活动后气短。”，得 0/1。
- 先问气短，再问“休息后会好转吗？”，第二轮要求学生换一种问法，得 0/1。修复时同时核对同句询问与有上下文的追问；追加无上下文或上一话题无关的对照，避免误披露别的症状。
- 分别核对病人回答和量表计分。量表要求“询问气短和呼吸困难”，改进建议还要求询问活动耐量和呼吸困难程度。保留两段原文及现有病例能提供的回答；单问气短的满分条件如需教学判定，保留待审。问齐后应可从封存分数追到实际回答的事件。
- 使用隔离模拟器复跑同一 110 场景，并单列上述六次措辞对照。真实供应商调用预算为 0。

其他独立开放项：APPY 的“有没有受伤？”仍可返回澄清；本轮计分修复没有修复该漏答。10 个歧义场景及 `f_ros`、`f_bowel` 拆分口径仍需教学审核。不要为使数字好看而改量表预期、补算未答内容或扩大披露。片段 ID 按顺序生成，修改病例措辞或拆分规则时必须重新核对其含义和病例版本，不能只看 ID 仍存在。
