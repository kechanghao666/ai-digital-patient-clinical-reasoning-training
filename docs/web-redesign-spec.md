# 新版 Web 前端设计规范（2026-11-13）

此前界面基于 Streamlit：每次操作整页重跑，组件结构与样式由框架决定，几轮视觉升级都卡在这些限制上。本轮在保留全部后端接口和安全边界的前提下，用 React + TypeScript 重建前端，采用用户选定的**明亮专业临床工作台**方向。旧 Streamlit 界面保留为备用入口。

## 研究要点与取舍

| 参考 | 学到的做法 | 落地 |
|---|---|---|
| Linear 2024 重设计 | 侧栏加顶栏组成“倒 L 形”全局框架，承载内容区；不活跃元素降低对比，“不要争夺没赢得的注意力”；对齐与密度精调，分隔线更柔和 | 固定左侧导航加顶部面包屑；未选中项用弱灰色；只有一个品牌强调色；1px 浅分隔线代替卡片阴影 |
| Material 3 规范布局 / SAP Fiori | 列表加详情、主区加辅助窗格；宽屏两到三栏，窄屏单栏推入；每个窗格有自己的操作栏 | 训练工作台用“对话主区 + 检查与病历辅助栏”；病例编辑用“版本列表 + 编辑详情”；小于 960px 时自动变成单栏 |
| NHS 设计系统 / WCAG 2.1 | 行长不超过约 80 字符、行高至少 1.5 倍、文字对比度至少 4.5:1；标题层级一致；医疗软件要考虑患者安全提示 | 正文 15px、行高 1.6；可读宽度上限；状态色不单靠颜色（同时有图标和文字）；“教学模拟”提示常驻顶栏 |
| Body Interact / DxR / OSCE（上一轮研究） | 问诊按结构化类别组织，结束后与专家路径对比 | 问诊结构进度放在对话区上方；复盘页提供五环节得分、扣分说明和事件回放 |

## 信息架构

- **学生**
  - 病例库：搜索、专科筛选、最近训练。
  - 我的训练。
  - 训练工作台：问诊与检查、病历与判断、处置与封存、复盘。
- **教师**
  - 班级看板。
  - 病例管理：版本列表、编辑、校验、送审、发布。
  - 反馈复核。
  - 评分复核。
- **通用**
  - 登录：独立账号或本地演示身份。
  - 顶栏常驻“教学模拟环境，非真实患者”。
  - 连接状态：显示是本地模拟还是 Nexent。

## 不变的边界

前端只是接口的展示层，所有权限、披露、评分和状态转换仍由后端判定，前端不保存任何隐藏病例信息：

- 学生端只调用学生接口，看到的病例数据与旧界面相同。
- 每个写操作都带 `request_id`。网络失败后重试时沿用同一个请求号，保证不会重复执行。
- 封存后所有输入都只读。
- 病历、诊断或鉴别有未保存的修改时，不允许封存，离开页面时会提示。
- 治疗必须勾选确认后才算实际执行，没确认的只算计划。
- 模型反馈未经教师复核不展示给学生。

## 2026-11-13 第三轮修订：专业临床系统风格

用户反馈上一版“AI味浓、不够高级”，具体问题有三点：功能不像真产品，文案啰嗦说教，视觉模板化。本轮按医院信息系统和 Oxford Medical Simulation 一类产品的做法修订。

视觉上，深蓝顶栏（#17324d）只放产品名、引擎模式、用户和“账号设置/退出”。其下是常驻的黄色教学模拟提示条，左侧是 196px 导航。面板圆角统一 3px，不用阴影；数据用紧凑表格和状态圆点表达。训练页顶部是患者条：性别年龄、主诉、科室、训练编号、模拟时间和已获病史。

文案上，按钮只用动词（开单、提交、执行、布置、导入），说明只写一句操作要点，不写解释和说教。复盘只列失分项；满分环节不重复“保持当前做法”；不向学生展示内部依据名。提示只保留最新一条，退出登录时清空。

功能上，首页按角色区分：教师进入“班级与任务”，学生进入“我的任务”。新增班级、名单导入、一次性初始密码、强制改密、任务布置、完成情况矩阵和 CSV 导出，补齐一门课真正需要的操作链。

验证：`web/e2e/smoke.mjs` 端到端 12 步全部通过。另有脚本检查，确认页面中使用的每个样式类都在 `styles.css` 中有定义。

## 2026-11-14 第四轮：监护仪风格与全院检查目录

用户指出两个问题：检查项是给定的，不合理；界面要更高级、更有科技感。

检查改为全院统一目录，所有病例相同，学生只能根据问诊自己判断开什么。目录每项标明类别、费用和回报时间，支持检索和按类别筛选。

视觉方向取自病床监护仪，没有用通用的“黑底加一个亮色”。深海军蓝底色（#0d1a24），颜色按监护参数的惯例表达含义：青色（#4cc9f0）表示可操作和主要读数，绿色（#58d68d）表示已回报和平稳，琥珀色（#f2b84b）表示待回报和费用，红色（#ff6b6b）表示病情恶化和错误。数值统一用 Bahnschrift，类似 DIN 的监护仪读数。

全页只有一处重点：训练页顶部的“监护带”，显示模拟时间、检查费用、已获病史和病情，配一条持续扫描的波形。波形只表示病情状态，不代表真实生命体征：平稳时为青色，恶化时变红、变快，提交后静止；系统开启“减少动效”时不动。其余部分保持克制：面板只用细边框，不加阴影；圆角分三级（面板 8px、控件 4px、筛选标签全圆）；去掉“A · B · C”式的中点拼接文字。
